{{- if and .Values.auth.enabled .Values.auth.admin.enabled }}

Authentication is enabled with the built-in admin account.

{{- if .Values.auth.secret.name }}
The admin password hash is read from Secret {{ .Values.auth.secret.name }} key `adminPasswordHash`.
{{- else }}
The generated admin password is stored in Secret {{ include "magos.authSecretName" . }}:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "magos.authSecretName" . }} -o jsonpath='{.data.adminPassword}' | base64 -d

{{- end }}

NOTE: For production, it is recommended to disable the admin account (auth.admin.enabled=false) and
      use OIDC instead (auth.oidc.enabled=true).
{{- end }}

  kubectl -n {{ .Release.Namespace }} create secret generic magos-oidc-secret \

  Then set auth.oidc.clientSecretRef.name=magos-oidc-secret when upgrading.
